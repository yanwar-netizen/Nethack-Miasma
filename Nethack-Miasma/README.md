# Nethack-Miasma
creating a nethack game(?).

Heyyo, this a classic nethack game made in C using ncurses, Nethack-Miasma!

**REQUIREMENTS:**

A linux environment or wsl.

**SETUP:**

1.) Install ncurses on your PC, try this link if you don't know how to install one https://www.cyberciti.biz/faq/linux-install-ncurses-library-headers-on-debian-ubuntu-centos-fedora/.\n
2.) Clone my repo and open the terminal.\n
3.) Change directory to the Nethack-Miasma folder.\n
4.) now execute `make` or `make all`.\n
5.) It should run ~~perfectly~~.\n

**HOW TO PLAY:**

1.) **WASD** for movement.\n
2.) **Q** to quit.\n
