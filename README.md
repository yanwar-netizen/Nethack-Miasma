# Nethack-Miasma
creating a nethack game(?).

Heyyo, this a classic nethack game made in C using ncurses, Nethack-Miasma!

**REQUIREMENTS:**

A linux environment or wsl.

**SETUP:**

1.) Install ncurses on your PC, try this link if you don't know how to install one https://www.cyberciti.biz/faq/linux-install-ncurses-library-headers-on-debian-ubuntu-centos-fedora/. 

2.) Download the latest release.

3.) change directory to the file containing the .AppImage and run `chmod +x Nethack_Miasma-x86_64.AppImage` in your terminal to make it an executable file.

4.) Now execute `./Nethack_Miasma-x86_64.AppImage` to run the game!


**HOW TO PLAY:**

1.) **WASD** for movement.

2.) **Q** to quit.
