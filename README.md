# Nethack-Miasma

Heyyo, this a classic nethack game made in C using ncurses, Nethack-Miasma!

There are 4 rooms on the map, they are the same on the same coordinates and size everyrun, only the doors and walk paths(somewhat) are randomized.


**REQUIREMENTS:**

You need a linux environment or wsl to run the AppImage file.

**SETUP:**

1.) Download the latest release.

2.) change directory to the file containing the .AppImage and run `chmod +x Nethack_Miasma-x86_64.AppImage` in your terminal to make it an executable file.

3.) Now execute `./Nethack_Miasma-x86_64.AppImage` to run the game!


**HOW TO PLAY:**

1.) After you run the file, you will be prompted to the Title screen of the game, Press any key to Continue to the map!

2.) `@` is you, the player. The `░ ═` are walls, while the `_` `|` are doors

1.) **WASD** for movement.

2.) **Q** to quit.
